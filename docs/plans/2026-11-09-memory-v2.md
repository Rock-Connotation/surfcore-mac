## 路线与编排

- B（采用、有门槛）：Host worker SQLite集中事务，复用渠道/角色/UI。收益为一致性与可检查性；成本为schema/迁移/运行时验证；风险为Host兼容和控制屏障。影子阶段关闭新功能保留V1可回退。

- Hybrid：P0运行时与调用图并行；主协调冻结公共契约；再按不交叉边界派发事务核、渠道适配、管理界面与测试；组合后独立审查。活跃Boundary归子代理所有。
