## 完整逻辑

1. **链路**。OneBot 入站 → QQ 桥接验证主人、私聊白名单、登录账号与角色 → 任务账本 → 本机文件创建 → 同一私聊回执。命令在普通聊天、模型和 Memory V2 入口之前处理。
2. **机制**。独立 `task-files.create-directory` 授权只允许一个本机私有目录。仅接受该目录当前层的 `.txt` 文件名和最多 2400 字节的 UTF-8 正文。写入并同步私有临时文件，重新确认授权和目录身份后以原子硬链接创建目标，目标存在时内核拒绝。随后清理自己的临时文件，校验目标身份、字节、权限和目录同步。
3. **影响面**。仅新建文本。现有目标、链接和目录保留。回执显示文件名和字节数，正文只写入目标文件。账本独立记录本机创建结果与 QQ 送达，重复消息不会再次执行。QQ 送达不明时可用 `任务状态 <任务编号>` 查询本机结果。
4. **取舍**。直接打开目标并排他写入的成本低，但中途中断可能留下半个文件。先完整写入后原子创建可避免暴露部分内容，保留一段同盘临时文件清理流程，回滚只需撤销授权或换回程序。
5. **生效**。创建目录授权并仅重启 QQ 桥接。NapCat 会话和 DSH 宿主无需重启。抖音与 B 站未纳入本次范围。
6. **验证**。隔离回归覆盖原样写入、已有文件及悬空链接、路径越界、重复入站、未授权私聊与群聊、撤权，以及文件已创建但 QQ 送达未知。真机读取同一 QQ 私聊回执并比对 Mac 文件的字节。
7. **回滚**。将 `task-files.create-directory` 移到备份即撤销新建权限。还原备份的 QQ 程序文件后重启桥接可完整回滚。保存已创建的目标文件和任务账本。

## 发布交接
