- 隔离根 `_backups/20261106-macos-wp0/isolated-dsh-home`；没有复制真实角色、Cookie、账号或配置。

## 根因

`safeJoinLibrary` 校验 symlink 后返回真实路径是安全契约；macOS `/var` 是 `/private/var` 的别名，fixture 将返回值与未规范化字符串相比，产生假失败。`test-stickers` 的离线配置断言却直接读取被忽略的用户 config.json，干净克隆必然失败。旧文档分支还未同步 Git 对象安装清单。

## 完整逻辑

1. 链路：audit → bridge VM fixture / voice fixture → safeJoinLibrary；stickers 离线配置检查 → 随仓库发布的 config.example.json。更新器与平台测试修复另见同日对应 case。
2. 机制：保留运行时真实路径和语音库约束；预期值调用 realpath，离线出厂配置检查只读 example。密钥配置不参与离线测试。
3. 爆炸半径：本组运行时进程变更 0、读者 0，运行时分值 0；只影响测试/路线文档，不碰用户数据、密钥、付费调用。
4. 取舍：A 改运行时返回表面路径，代码少但改变安全路径语义；B 规范化 fixture 预期值，保留所有安全断言，成本小、回滚简单，选 B。配置可复制用户配置或改读 example；选后者使测试可复现并隔离账号。
5. 生效与重启：下一次运行测试即生效，本组无需重启 App/QQ；真实插件安装尚未进行。
6. 验证：见下表和忽略目录原始日志；不把平台跳过计成对应 Windows 场景通过。
7. 回滚与残余：原件在 `_backups/20261106-macos-wp0/`；回退明确测试/文档文件即可，无用户状态迁移。WP1—WP5 与真实宿主、ASR、Intel/Windows 实测仍待完成。
